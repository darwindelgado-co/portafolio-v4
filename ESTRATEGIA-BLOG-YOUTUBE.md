## 🎥 Herramientas Recomendadas para Videos

### Captura de pantalla:
- **OBS Studio** (libre, profesional)
- **ScreenFlow** (Mac)
- **Camtasia** (pago, muy fácil)

### Edición:
- **DaVinci Resolve** (libre, profesional)
- **CapCut** (gratuito, móvil)
- **Premiere Pro** (pago)

### Micrófono:
- Audio Technica AT2020 (buena calidad)
- Blue Yeti (si ya tienes)

### Consejos para videos:
1. **Terminal con buena fuente:** Hack, JetBrains Mono, Fira Code (tamaño 18+)
2. **Fondo limpio:** Dark mode en terminal
3. **Ritmo:** Habla claro, pausa entre temas
4. **Timestamps en descripción:** Ayuda a los viewers
5. **Subtítulos:** En YouTube auto-genera, revisa y ajusta
